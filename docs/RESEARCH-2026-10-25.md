# 头颈癌工作台 · 调研主文档（2026-10-25）

> 病种：头颈癌（Head and Neck Cancers）｜一期做厚：**喉 + 下咽 + 口腔**；鼻咽癌作次场景；口咽（HPV+）只保留字段
> 方法依据：`docs/21-RESEARCH-PLAYBOOK.md`（三件套：主文档 + `research/` 证据稿 + 回写既有文档）
> 证据分级：**A**（≥2 独立来源交叉）／**B**（单一可信来源）／**未核实**（仅官网自述或推断）

---

## 0. 一句话结论

头颈癌不是"一个部位的癌"，是**六个原发部位 × 两条治疗路径（手术 / 放疗）× 三个可能失去的功能（声音、呼吸通道、吞咽与外形）**的组合。
产品能不能立住，取决于**是否把"失去声音"和"气管造口是气道不是造口"这两件事当成一等结构**，而不是当成"术后注意事项"里的一条。

## 1. 调研问题与证据边界

五个问题（每个都落到"工作台给什么"）：

| # | 调研问题 | 落到哪条线 |
| --- | --- | --- |
| Q1 | 患者确诊后最先要弄清的是"我哪个部位、哪一期、要不要切喉"——这三件事的先后与表达是什么？ | L2 疾病本体线 |
| Q2 | 全喉切除后"说不出话"这件事，在生活里具体卡在哪几个动作上（打电话、点餐、急诊说不清）？ | L3 治疗线 / L5 安全线 |
| Q3 | 气管造口在居家场景里，哪些情况是**分钟级**的，哪些可以等到门诊？ | L5 安全与症状线 |
| Q4 | 放疗结束后的十年里，哪些问题是"当时没事、后来才来"的？患者怎么知道自己该查什么？ | L4 指标线 / L8 随访线 |
| Q5 | 吞咽与营养在这条线上为什么不能只做"体重记录"？ | L6 营养与体重线 |

**证据边界（必须写在最前面）**：

- 本项目**没有开展患者访谈、没有临床医生审核、没有患者组织核验**（与膀胱癌项目同一约束：只做桌面研究）。
- 因此本文所有"患者诉求"均来自**文献与共识中记载的症状负担与关切条目**，**不是**本癌种患者对本产品的原话。凡属推断，标 `未核实`。
- 医学结论只照抄来源，不做外推；来源未覆盖的，写"来源未覆盖"。

## 4. 头颈癌的十二条维度

> 判定口径：**"只有本癌种才成立"**。凡是"任何癌种都能写"的，删掉。

| # | 维度 | 为什么只有头颈癌成立 | 证据 | 对产品的含义 |
| --- | --- | --- | --- | --- |
| D1 | **原发部位** | 口腔/口咽/喉/下咽/鼻咽/唾液腺的手术范围、功能损失、放疗靶区、随访方式**全不同**；同为"头颈癌"的两个患者可能没有任何共同治疗经历 | 结构事实（指南通用，本地无主指南→`未核实`其分层细节） | 部位必须是**贯穿全站的一等字段**，不是备注。首页第二问就是部位 |
| D2 | **HPV/p16 状态（口咽）** | 同一分期、不同 HPV 状态，预后与治疗强度不同；公开信息常把两者混算 | 本地无指南覆盖→`未核实` | 只保留字段 + "这个结果代表什么要问医生"，不做厚（DESIGN-01） |
| D3 | **手术方式与切除范围** | 部分喉切除 vs 全喉切除 vs 咽全喉切除，是"还能不能用自己的声音"的分界；口腔还要分是否重建、是否切下颌骨 | EV-03、EV-06 | 手术页必须**按术式分支**，不能一条时间线 |
| D4 | **气管造口（气道，不是"造口"）** | 全喉切除后造口是**唯一的呼吸通道**，不是排泄口的一个变体。堵管/脱管是**分钟级**事件 | 结构事实；EV-06 佐证误吸风险 | 必须有独立入口 + 急症页置顶；耗材与"造口"（肠造口）语义必须分开 |
| D5 | **发声康复** | 三种发声方式（食管语 / 电子喉 / TEP 发音管）是三条不同路径；发音管有**更换周期**（EV-04：115 天/3.15 次每年） | EV-03、EV-04 | 发声方式是一等字段 + 更换记录 + "现在能说到什么程度" |
| D6 | **吞咽与误吸** | 术后与放疗后都可能出现；误吸可无症状（沉默性误吸） | EV-06（放疗史者风险更高） | 吞咽单独成线，不能塞进"营养"；要有"进食方式"字段（口进/胃管/PEG） |
| D7 | **放疗急性反应** | 口腔黏膜炎发生率高且分级明确（EV-01） | EV-01、EV-02 | 黏膜炎是**可分级**指标，但分级口径需裁决（§7-G2） |
| D8 | **放疗晚期毒性（十年轨道）** | 口干、龋齿、放射性骨坏死、牙关紧闭、吞咽困难、颈动脉狭窄、甲状腺功能减退——**治疗结束多年后才出现**，且"放疗后拔牙"是明确风险点 | 共识目录覆盖口腔管理；ORN/牙关紧闭细节本地未取到原文→`未核实` | 需要"治疗结束第 N 年"的时间轴，不是"本次复查" |
| D9 | **颈清扫后肩臂功能** | 副神经损伤导致肩综合征，影响梳头、穿衣、提物；这是**天天在承受但很少主动说**的 | 本地无来源→`未核实` | 功能维度用"能不能做到某个动作"，不用量表分数 |
| D10 | **外形与社交** | 面部瘢痕、组织缺损、造口外露；影响出门、拍照、工作 | EV-03（社交接触问题） | 社交场景要具体（戴口罩/围巾/吃饭/说话被听不清） |
| D11 | **心理与病耻感** | 失声者**在文字互联网里天然缺席**——无法打电话、语音助手用不了、别人听不清就放弃沟通 | EV-03（社交接触）、EV-09（消极抵抗） | 交互不能只靠打字；家属代记是刚需旁路 |
| D12 | **复发与随访** | 复发/转移（rHNC）有独立工具形态（PCI）；随访含影像、内镜、甲状腺功能 | EV-05 | 关切清单（PCI 式）比"问题清单"更贴合 |

**横切项**（不进十二条，但是结构层）：营养与体重（并入 C 轨）、经济负担（EV-03 明确列出，作为独立字段而非"备注"）。

## 5. 四条轨道（不可通约的量）

依据 `docs/27-TRACKS-AND-METRIC-CARDS.md` §0 的触发信号——本癌种存在**四个不能相加的量**：

```
A 轨 · 肿瘤学状态    分期 / 病理 / HPV / 复发        ← 决定"还有哪些治疗手段"
B 轨 · 气道与发声    造口状态 / 发声方式 / 发音管     ← 决定"能不能呼吸、能不能说话"
C 轨 · 吞咽与营养    进食方式 / 体重 / 误吸           ← 决定"能不能吃、会不会呛"
D 轨 · 放疗晚期毒性  口干 / 牙齿 / 张口度 / 甲功      ← 决定"十年后还要防什么"
```

四条硬约束照抄 §1：**永不加总、永不折算、各自独立归一化、分类变量只画节点**。

> 判据：如果页面上能让用户算出"我总体几分"，说明轨道没分开。
> 反例警戒：把 B 轨塞进 A 轨（"造口是术后并发症"）→ 患者读到的是"这是我的病的一部分"，而不是"这是我每天要维护的通道"。

## 6. 与膀胱癌的结构差异（防套模板自查）

依据 `docs/26-CANCER-FEATURE-LINES.md` §4.1 判据：**两个癌种一级名称一致率 > 70% 且二级顺序一致 → 没认真做本癌种调研**。

| 轴 | 膀胱癌（已交付） | 头颈癌（本癌种） | 差异性质 |
| --- | --- | --- | --- |
| 分野 | NMIBC vs MIBC（保膀胱 / 切膀胱） | **六个原发部位 × 手术 vs 放疗 × 是否失去声音** | 膀胱是二分；头颈是三维组合 |
| 决定性损失 | 膀胱（器官去留） | **声音（全喉）、呼吸通道（终身造口）、吞咽与外形** | 膀胱只有一个"失去"；头颈有三个且可叠加 |
| 长周期变量 | 灌注 3 年、膀胱镜复查、上尿路监测 | **发音管 115 天更换、放疗十年毒性、牙关紧闭、颈动脉狭窄** | 头颈的长周期**跨十年**且多为"迟发" |
| 急症 | 血块填塞、BCG 全身感染、造口缺血 | **气管造口堵管/脱管、误吸与吸入性肺炎、放射性骨坏死、颈动脉破裂先兆** | 头颈的急症**分钟级**且与呼吸直接相关 |
| 生活维度 | 造口耗材与社交 | **发声方式与社交、吞咽、外形、口罩围巾** | 头颈多一层"沟通本身" |
| 交互门槛 | 能打字即可 | **失声者不能打电话、语音助手失效** | 头颈必须解决"不能打字/不能说话"的人怎么用 |
| 指标分级 | CTCAE v5.0 直接对照 | **黏膜炎共识主张 WHO/RTOG，CTCAE 仅参考** | 分级口径需裁决，不能照搬 |

**结论**：一级线命名与二级顺序**不得**沿用膀胱癌那套（看板/病情整理/分型分期/手术/灌注/改道/治疗历程/复查/指标/一图秀/急症/生活/复诊/试验）。头颈癌的线必须由 §4 十二条维度重新长出。
