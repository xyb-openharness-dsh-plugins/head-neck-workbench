# 差异化矩阵（DIFF-MATRIX）

> G1 准入门槛：**≥3 条 S→F→A**，且每条要落到五层（场景 / 模块 / 字段 / 交互 / 验收）。
> 「提到一次」不算覆盖。通用能力（登录、导出、指标卡）不能用来证明本癌种需求扎实。
> 本文件只回答一个问题：**为什么这个工作台必须为头颈癌单独做，而不能拿别的癌种改个名。**

日期：2026-10-25 ｜ 对应原型：`prototypes/v0.1/index.html` ｜ 场景来源：`docs/SCENARIOS.md`（S01–S17）

## 0. 判据

| 列 | 含义 |
| --- | --- |
| **S**（场景） | 患者身上真实发生的一件事，有触发条件与时间压力。必须能指到 `docs/SCENARIO-PATHS.md` 的编号。 |
| **F**（功能） | 落在哪个一级/二级页签、读写哪些字段（字段名取自 `schema/draft/0001_initial.sql`）。 |
| **A**（验收） | 可执行的判断，不是「体验良好」。能指到 `scripts/verify_prototype.py` 的断言名或一条可复现的走查。 |
| 五层 | 场景 / 模块 / 字段 / 交互 / 验收 —— 五格都填满才算落地。 |

## D1 原发部位决定一切（六个部位不是同一套流程）

- **S**：`S12 报告上写 CPS 80` 与 `S07 说不出话怎么报警` 是**两种病人**。口腔癌患者能说话、能吃饭，担心的是外形与复发；喉癌患者术后失声，担心的是「打不了 120」。同一份「我的病」页面按喉癌写，口腔癌患者读到一堆用不上的气道内容；按口腔癌写，喉癌患者找不到急救入口。
- **F**：`我的病 › 原发部位与范围`（`subjects.primary_site`，取值 口腔/口咽/喉/下咽/鼻咽/唾液腺）+ 全局**部位开关**：选择后，`气道与造口`、`声音与沟通` 两个一级在非喉/下咽部位默认折叠但**不删除**。
- **A**：`verify_prototype.py` 断言「部位切换后气道一级折叠但仍在导航中」；走查：把部位从「喉」切到「口腔」，气道与声音两栏折叠、其余不变，且**没有任何一条内容被删掉**。
- 五层：场景 ✅（S12/S07 两条路径）｜模块 ✅（我的病›原发部位与范围 + 全局折叠规则）｜字段 ✅（`subjects.primary_site`）｜交互 ✅（切换即折叠，可展开）｜验收 ✅（断言 + 走查）

## D2 HPV+ 口咽癌与烟酒相关口腔癌是两条病

- **S**：`S12 报告上写 CPS 80`——患者拿到一份写着「CPS 80」的病理，不知道这个数只对口咽/头颈鳞癌的免疫治疗有意义，也不知道自己是不是 HPV 相关（预后与随访强度完全不同）。
- **F**：`我的病 › 分期与病理` 增加 `pathology_reports.hpv_status`（阳性/阴性/未检测）与 `p16_status`；`指标分析 › 分级说明` 解释 CPS 是「每 100 个活肿瘤细胞里有多少个带 PD-L1」，**CPS 可以大于 100**（EV-07 原文），不能当百分比读。
- **A**：`verify_prototype.py` 断言病理页渲染 HPV 三态与 CPS 说明；走查：CPS 说明里必须出现「可大于 100」与来源标注，且**不出现**「CPS 高就一定能用免疫治疗」这类因果句。
- 五层：场景 ✅｜模块 ✅（分期与病理 / 分级说明）｜字段 ✅（`hpv_status`、`p16_status`）｜交互 ✅（三态选择 + 解释卡）｜验收 ✅

## D3 保喉 vs 全喉切除，代价是声音

- **S**：`S03 发音管该换了`、`S14 别人听不清就懒得说了`。全喉切除后患者用发音管说话，发音管平均 **115 天**就要换、约 **3.15 次/年**（EV-04, PMID 42815565）；且 TL-F（发音管）患者的吞咽负担、社交接触、经济困难**持续更重**（EV-03, PMID 42859059）。
- **F**：`声音与沟通` 三个二级（发声方式与发音管 / 能说到什么程度 / 说不出来的时候）；字段 `surgery_events.procedure`（含全喉/部分喉）、`voice_rehab.method`、`voice_rehab.prosthesis_changed_on`。
- **A**：`verify_prototype.py` 断言「发音管更换提醒按 115 天推算，且页面标注这是文献均值不是医嘱」；走查：录入上次更换日期后，页面给出「约 N 天后可考虑更换」并附来源，**不写「必须更换」**。
- 五层：场景 ✅（S03/S14）｜模块 ✅（声音与沟通 3 二级）｜字段 ✅｜交互 ✅（录入日期 → 推算提醒）｜验收 ✅

## D4 放疗十年毒性（口干 / 吞咽 / 张口受限 / 放射性骨坏死 / 放疗后拔牙禁忌）

- **S**：`S05 放疗后第三年牙疼`。头颈放疗患者**拔牙前必须告知放疗史**，否则有放射性骨坏死（ORN）风险；而患者三年后去看牙医时，往往已经不记得自己做过放疗。
- **F**：`长期与复诊 › 放疗后十年`（`late_effects` 表：口干/吞咽/张口受限/颈部纤维化/听力/甲状腺）+ `口腔与牙齿`（`dental_events` 表：事件/是否告知放疗史）；指标 `mouth`（张口度 mm）、`tsh`（放疗后甲减）。
- **A**：`verify_prototype.py` 断言牙科记录必须带 `rtDisclosed` 字段且页面显式提示「看牙前要说放疗史」；`measure-one-chart.py` 实测张口度 42→33mm 趋势可见（C1/C5/C6 通过）。
- 五层：场景 ✅（S05）｜模块 ✅（放疗后十年 / 口腔与牙齿）｜字段 ✅（`late_effects.*`、`dental_events.rt_disclosed`、`mouth`/`tsh` 指标）｜交互 ✅（牙科事件强制勾「是否告知放疗史」）｜验收 ✅

## D5 气管造口是「气道」，不是别的癌种的「造口」变体

- **S**：`S01 醒来发现脖子上有个洞`、`S02 半夜造口堵了`。气管造口堵管/脱管是**分钟级**急症，和肠造口的渗漏/气味完全不是一回事——照搬肠造口模板会把「底盘多久换一次」放在第一屏，而真正救命的是「堵了怎么办」。
- **F**：`气道与造口` 四个二级（我的气道 / 造口日常 / 耗材与库存 / **堵管与脱管**）；字段 `airway_facts.kind`（气管造口/经口/部分喉）、`airway_emergency`（堵管处置步骤）。
- **A**：`verify_prototype.py` 断言「气道首页第一屏是急症入口，不是耗材清单」；走查：进入气道一级，首屏可见「堵了/掉了怎么办」，耗材库存排在其后。
- 五层：场景 ✅（S01/S02）｜模块 ✅（气道与造口 4 二级）｜字段 ✅（`airway_facts`、`airway_emergency`）｜交互 ✅（急症优先的信息层级）｜验收 ✅

## D6 颈清扫后肩臂功能与面部外形

- **S**：`S13 肩膀抬不起来`。颈清扫（尤其根治性颈清扫）后副神经损伤导致肩不能外展、梳头做不到；这是**功能**问题，用「疼不疼」问不出来。
- **F**：`长期与复诊` 增加肩臂功能条目（`shoulder_function`：梳头/抬臂/提物 三动作能否完成）+ `surgery_events.neck_dissection`（是否清扫/侧别/类型）。
- **A**：`verify_prototype.py` 断言肩臂条目用「动作能否完成」而不是疼痛评分；走查：三项动作各可选「能做到 / 做不到 / 部分」，回首页显示「肩臂功能：梳头做不到」。
- 五层：场景 ✅（S13）｜模块 ✅（长期与复诊）｜字段 ✅（`shoulder_function`、`neck_dissection`）｜交互 ✅（三动作选择）｜验收 ✅

## 1. 反例：这些**不是**差异（防止自我感动）

| 看起来像差异 | 为什么不算 |
| --- | --- |
| 指标卡 / 一图秀 / 导出 | 通用能力。所有癌种都有，不能用来证明头颈癌需要单独做。 |
| 「心理与家人」一级 | 通用。头颈癌的特殊性在于**失声导致的社会隔离**（S14），这条已归入 D3，不是靠一个「心理」页签算覆盖。 |
| 「复诊带什么」 | 通用。头颈癌的特殊性在 D4（放疗十年毒性）与 D6（肩臂功能），不在这页本身。 |
| 登录 / 设置 / 帮助 | 基建。 |

## 3. 未覆盖 / 待定
