## 1 定义（`definition`）

头颈癌是一组起源于头颈部（口腔、咽、喉、鼻腔与鼻窦、唾液腺等）的恶性肿瘤的统称。原发部位决定治疗路径与功能代价，所以本台把「原发部位与范围」放在第一页，而不是先讲分期。

- 头颈癌不是一种病：按原发部位分口腔、口咽、喉、下咽、鼻咽、鼻腔鼻窦、唾液腺等，各部位的病理类型与治疗路径不同。
- 病理以鳞状细胞癌为主；鼻咽癌等部位另有其病理与病毒相关背景（如 EBV）。本台只记报告原文，不做病因推断。
- 口咽癌的 HPV 与 p16 状态单列记录；本台不据检测结果推断病因或预后，只保留原值与检测方法。
- 分期按 AJCC 第 8 版记录（原型与演示档案使用该口径）；TNM 原文照抄，不由部位推导。
- 功能代价（发声、吞咽、气道）与原发部位、手术与放疗范围相关，单列「气道与造口」「声音与沟通」两页。

- 不写「预后差 / 恶性程度高 / 发展快」这类判读。
- 口咽癌与非口咽癌的分期规则不同，本台不替医生判断适用哪一套。

## 3 目前治疗全景概要（`landscape`）

按**原发部位 / 病期 / 线序**分组，每组只列「指南与共识列举过的手段类别」，不排序、不比优劣。

### 3.1 初诊（按原发部位与病期）

- 手术：原发灶切除与颈淋巴结清扫被列出，术式与切除范围按手术记录原文照抄。
- 放疗：外照射单独使用或术后使用都被列出；照射范围按放疗记录原文记录。
- 同步放化疗：在部分部位与病期被列为可讨论选项。
- 靶向治疗：EGFR 单抗与放疗联合的情形被列出。
- 免疫检查点抑制剂：在复发 / 转移情形被列出，并按 PD-L1 CPS 等检测结果分层。

### 3.2 喉功能保留与发声

- 保喉策略：部分喉切除、放疗或放化疗作为保留喉部的路径被列出；是否适用由部位、分期与医生评估决定。
- 全喉切除后的发声方式：食管音、发音管（TEP）、电子喉都被列出。
- 造口与气道护理：造口日常、耗材与堵管 / 脱管的应对被单列为记录项，本台不给处置建议。

### 3.3 复发 / 转移后

- 再次手术、再次放疗与全身治疗（化疗、靶向、免疫）都被列出。
- 临床研究：指南与共识把「参加登记良好的临床试验」列为一项正式选项。

### 3.4 贯穿全程

- 吞咽与营养：进食途径（口进 / 胃管等）与体重按记录原文呈现；本台不给食谱与补充剂剂量。
- 随访与观察项：颈部 + 胸部影像、喉镜 / 造口检查按医生给的间隔记录；口腔黏膜炎按 WHO 分级对照，放射性骨坏死与牙关紧闭只列观察项。

## 7 本项目教训

1. **模块接管按钮时不会补 `aria-label`，只补 `aria-expanded`。** 本原型没有 `.top-actions`，若手写按钮只写 `aria-label="疾病概要"`，P1 会 FAIL——探针要求 label 里出现「定义」和「趋势」。最终把四段全写进 label。
2. **这个项目没有 `--brand`，直接复制 CSS 会落到紫色兜底。** 项目只有 `--teal` 一套令牌；只在 `primer.css` 末尾追加三个颜色变量映射（`--dp-accent` / `--dp-accent-deep` / `--dp-accent-soft`），不动任何结构规则。
3. **草案不能写成发布。** `docs/SOURCES.md` 里 M01 的标准号仍是 `T/XXX XXXX—XXXX` 占位，趋势段只能写「仍为草案」，写成「已发布」就是假事实。
