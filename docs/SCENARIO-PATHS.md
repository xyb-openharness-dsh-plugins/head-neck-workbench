## 0. 两条通道的分工（用户 2026-10-24 原话落地）

| 场景类型 | 默认通道（AI 协助） | 手工通道（进阶） |
| --- | --- | --- |
| 首次建档、一次性描述（术式、部位、放疗结束时间） | 对 AI 说一句 → 系统出草稿 → **逐项核对** → 入库 | 页面内「编辑」小表单 |
| 高频重复录入（体重、耗材、呛咳次数） | 批量说/贴（"这周体重 62、61.5、61"）→ 出多行草稿 | 表格行内录入 |
| 精确数值与日期（CPS 80、放疗结束 2023-04-11） | AI 出草稿但**数值必须人工确认**后才入库 | 直接填数字/日期选择器 |
| 私密内容（性、外形、情绪） | **不走 AI**，默认手工录入且默认私密 | 唯一通道 |

三条纪律：① AI 只出**候选**，不自动入库；② 私密项不进 AI 提示词与导出（`buildAIPrompt` 里逐条列「没有带入的内容」）；③ 手工表单不因为「AI 能代劳」而被删掉——低精力与断网时它是唯一出路。

## 1. 十七条路径

格式：入口（首页哪个卡/按钮）→ 路径 → 产物 → **回首页看到什么变了** → 失败恢复。

### S01 醒来发现脖子上有个洞
- 入口：看板 › 今天要知道的 ›「造口状态」卡
- 路径：看板 → 气道与造口 › 我的气道（这条通道是唯一呼吸入口）→ 声音与沟通 › 说不出来的时候
- 产物：一张可打印急救卡 + 术式/造口/发声方式三条记录
- 回首页变化：今天要知道的顶部出现「急救卡已生成 · 可打印」，造口状态由「待确认」变「终身造口」
- 失败恢复：不知道术式时留空并显式标「不知道」，不阻断；急救卡单页自包含，断网可打开

### S02 半夜造口堵了
- 入口：看板 › 今天要知道的 › 置顶红色条「喘不上气 / 造口堵了」
- 路径：→ 气道与造口 › 堵管与脱管（置顶、单页可离线）
- 产物：一张「立刻就医 vs 可以等门诊」的分界卡（不写处置步骤）
- 回首页变化：无记录变化（急症路径**不要求**先录入）；回首页红色条仍在
- 失败恢复：任何输入都不阻断；不要求登录/联网/填表才能看到分界

### S03 发音管该换了
- 入口：声音与沟通 › 发声方式与发音管（看板「最近变化」在漏气记录后出现）
- 路径：录入置入日期与更换记录 → 页面算「距上次 N 天」
- 产物：一条更换记录 + 距上次天数 + 文献均值 115 天（标明是均值不是个人预测）
- 回首页变化：「最近变化」出现「发音管已使用 N 天」，超过 115 天时卡片加一句「可以问医生要不要换」
- 失败恢复：只记得月份时按「仅月份」存，页面显示「2026-03（仅月份）」且不参与天数计算

### S04 吃饭总呛
- 入口：吞咽与营养 › 呛咳与误吸（看板「今天要知道的」在放疗史存在时带出）
- 路径：记录「什么形态呛 / 有没有咳出来」→ 页面提示沉默性误吸
- 产物：一条呛咳记录（形态、是否咳出、日期）+ 一句「放疗史者风险更高（来源）」
- 回首页变化：「今天要知道的」出现「近 7 天呛咳 N 次」；N≥3 时提示「复诊时说一下」
- 失败恢复：分不清形态时选「说不清」，记录仍成立；不因缺字段拒收

### S05 放疗后第三年牙疼
- 入口：长期与复诊 › 放疗后十年
- 路径：录入放疗结束日期 → 页面算「第 N 年」→ 给出「放疗史必须告诉牙医」提示
- 产物：一条放疗史记录（结束日期 + 部位 + 剂量原文照录）+ 一张给牙医的说明
- 回首页变化：「长期与复诊」在「今天要知道的」里出现「放疗后第 3 年 · 看牙前要说明」
- 失败恢复：不知道剂量时留空标「不知道」；只记得年份时按「2023（仅年份）」存

### S06 体重掉了八斤
- 入口：吞咽与营养 › 体重（看板「最近变化」在体重下降后出现）
- 路径：录入体重 → 与「进食方式」同屏 → 若口进且持续下降，提示「可以问医生要不要营养支持」
- 产物：体重趋势 + 进食方式并列 + 一句「可以问医生」
- 回首页变化：「最近变化」出现「体重 −4.0 kg（近 2 个月）」；指标页同步出现该点
- 失败恢复：只有一次记录时**不画线**，写「仅一次记录，无法比较」

### S07 说不出话怎么报警
- 入口：声音与沟通 › 说不出来的时候（同 S01，急救卡）
- 路径：填诊断/术式/造口/过敏/联系人 → 打印
- 产物：一张可打印急救卡（写明「不能经口鼻呼吸」「不要只看我的嘴」）
- 回首页变化：今天要知道的出现「急救卡已生成」
- 失败恢复：联系人不填也能生成（留空显示「未填」）；打印样式 `@media print` 已在原型验证

### S08 家里人不知道该做什么
- 入口：心理与家人 › 家里人要做什么
- 路径：照护者清单（造口湿化 / 耗材补货 / 复诊陪同 / 记录代录）→ 勾选本周要做的
- 产物：一张照护者清单 + **「本页记录人」与「记录的是谁」两个独立字段**
- 回首页变化：看板出现「照护者：本周 3 项待办」
- 失败恢复：照护者没有账号时用「代录」模式，记录人字段写照护者名字，不改患者主体

### S09 我怕但不想跟家里说
- 入口：心理与家人 › 我现在的感受
- 路径：手工录入（**默认私密，不走 AI**）
- 产物：一条私密感受记录
- 回首页变化：**首页无任何变化**（私密项不进摘要、不进一图秀、不进导出）——这是刻意设计
- 失败恢复：出现自伤念头时页面直接给「联系当地急救或你的治疗团队」，不做危机干预话术

### S10 复诊前想不起来要问什么
- 入口：长期与复诊 › 关切清单
- 路径：新增一条「担心什么」→ 复诊后回填「问了没有 / 医生怎么答（原文）」→ 长期与复诊 › 复诊带什么 → 打印
- 产物：一页复诊摘要（可打印）+ 问题清单（含「有没有被回应」）
- 回首页变化：「今天要知道的」出现「有 2 个问题还没问」；复诊日期临近时置顶
- 失败恢复：医生没回答时选「没答上」，不假装已解决；摘要缺块时写明缺哪块

### S11 免疫治疗后身上起疹子
- 入口：治疗与手术 › 用药与不良反应
- 路径：记录症状 + 出现时间 + 关联的治疗 → 页面只记录不判断
- 产物：一条不良反应记录（症状、起始日、关联方案）
- 回首页变化：「今天要知道的」出现「新记录的不良反应：皮疹（第 3 天）」
- 失败恢复：不确定是否与药相关时选「不确定」，页面保留但不给因果

### S12 报告上写 CPS 80
- 入口：我的病 › 病理报告原文
- 路径：照录 CPS 数值 + 检测方法 + 标本类型 → 我的病 › 名词与不确定
- 产物：一条病理原文记录 + 一段「CPS 分子含淋巴细胞与巨噬细胞，可以 >100，不等于肿瘤细胞阳性比例；CPS 与 TPS 不是同一把尺」
- 回首页变化：无（知识型场景，不产生待办）
- 失败恢复：报告没写检测方法时留空标「报告未提及」，不猜

### S13 肩膀抬不起来
- 入口：治疗与手术 › 手术与切除范围
- 路径：录入颈清扫分区 + 副神经是否保留 → 功能自述「梳头/穿衣/提物能不能做到」
- 产物：一条手术范围记录 + 三条功能自述
- 回首页变化：「最近变化」出现「肩臂功能：梳头做不到（新）」
- 失败恢复：不知道副神经是否保留时留空标「不知道」，不推断

### S14 别人听不清就懒得说了
- 入口：心理与家人 › 说不出口的事（默认私密）
- 路径：手工录入社交退缩/外形/性 → 声音与沟通 › 能说到什么程度（客观描述）
- 产物：一条私密记录 + 一段「能说到什么程度」的自述
- 回首页变化：**首页无变化**（私密）
- 失败恢复：不想写就不写，页面不催；不进 AI 提示词

### S15 抽血单出来一堆箭头（补：指标页的孤儿来源）
- 入口：看板 › 今天要知道的 ›「有新检验报告」
- 路径：资料与导出 › 我的资料与草稿（贴/拍照）→ 逐项核对 → 指标分析 › 指标卡片 / 一图秀
- 产物：若干条观察记录（带单位、采样日、机构与方法）+ 指标卡（正面最近值/背面趋势）
- 回首页变化：「今天要知道的」出现「新指标：血红蛋白 108 g/L（偏低，对照 CTCAE 2 级）」
- 失败恢复：单位认不出时留空并标「单位待确认」，不进趋势；换机构/换方法时拆可比组并断线

### S16 资料散在手机相册里（补：资料页的孤儿来源）
- 入口：资料与导出 › 我的资料与草稿
- 路径：把报告拖进来 → 系统出「待核对草稿」→ 逐项确认 → 入库；或直接导出
- 产物：一份资料清单（每份带来源、日期、核对状态）+ 一份可导出的档案
- 回首页变化：「今天要知道的」出现「3 份资料待核对」
- 失败恢复：解析失败时保留原件与失败原因，允许手工录入；看不清的字段留空不猜

### S17 医生说换方案，我听不懂第几线（补：治疗线页的孤儿来源）
- 入口：治疗与手术 › 治疗线
- 路径：录入「第几线 / 方案名 / 开始日期 / 为什么换」→ 旧线标「已结束」不删除
- 产物：一条治疗线记录（含换线原因原文）+ 时间轴
- 回首页变化：「今天要知道的」出现「当前方案：XX（第 2 线，2026-09 起）」
- 失败恢复：不知道第几线时选「说不清」，仍记录方案名与日期，不猜线数
