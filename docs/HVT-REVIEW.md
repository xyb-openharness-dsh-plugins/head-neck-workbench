## 1. 方法与口径

疾病轴（本癌种在十条轴上的差异，逐条填）：

| 轴 | 头颈癌的差异 | 派生场景 |
| --- | --- | --- |
| A1 病理与分子 | 原发部位（口腔/口咽/喉/下咽/鼻咽/唾液腺）决定分型与治疗；HPV+ 口咽 vs 烟酒相关是两条病；PD-L1 CPS 可 >100 | S12 |
| A2 解剖后果 | 全喉切除 → 永久气管造口（**唯一**呼吸入口，不是伤口）；颈清扫 → 肩臂功能；唾液腺切除 → 口干 | S01、S13 |
| A3 分期体系 | TNM 第 8 版；鼻咽用独立分期体系，**不能与其它部位混比** | 建档路径（S12 旁） |
| A4 治疗组合 | 手术/放疗/化疗/靶向/免疫按部位分叉；**保喉 vs 全喉**是核心岔路；鼻咽以放疗为主干、手术不是常规 | S17、S05 |
| A5 复发部位 | 局部/区域（颈淋巴结）为主；远处肺/骨；鼻咽远处转移比例更高 | 随访记录（待挂场景） |
| A6 治疗毒性 | **放疗十年毒性**（口干、吞咽、张口受限、放射性骨坏死、放疗后拔牙禁忌）；irAE；顺铂肾毒性 | S05、S11 |
| A7 功能与生活 | 声音（发音管/电子喉/食管语）、吞咽与误吸（沉默性误吸）、肩臂功能、面部外形、社交退缩 | S03、S04、S13、S14 |
| A8 随访节奏 | 头颈专科查体 + 影像；**不靠血清标志物**（与卵巢/乳腺不同）；甲状腺功能（放疗后） | 随访记录（待挂场景） |
| A9 急症边界 | **堵管/脱管是分钟级**；出血（颈动脉暴露）；误吸窒息；放疗后气道水肿 | S02、S07 |
| A10 照护者 | 造口湿化、吸痰、耗材补货、代述（患者说不出话时） | S08 |

打分：V/S/F 各 1–3；HVT 门槛 V≥2 且 S≥2；优先级 P = V×S×(5−C)。五层 S/M/F/I/A 各 0 或 1。**本报告 C 均为人工判读，未跑 `hvt_scan.py` 术语命中初值**（脚本内置五癌种术语包无头颈癌，`--terms` JSON 待写，见 §8 待办）。

## 4. 差异评价

### G1 S07 急救卡缺字段（唯一 G 级）

- 现象：急救卡是本项目价值最高的产物之一（患者说不出话时唯一能救命的东西），但数据模型里**没有承载它的结构化字段**。
- 证据：`schema/draft/0001_initial.sql` 的 `subjects` 只有 `display_name / birth_year / sex / primary_site / site_detail`；全文 `grep -nE "allerg|contact|emergency" schema/draft/0001_initial.sql` → 0 命中。`exports` 表无 `template` 字段。
- 影响：照现有 schema 实现，急救卡的过敏与联系人只能塞进 `subjects.note` 或前端硬编码 → 换患者时带错信息，且无法在导出时校验完整性。
- 处置：见补丁 P1。

### U 待核验 6 条

1. **CTCAE 阈值**：`docs/METRIC-TREND-SPEC.md` 仍空模板，「分级说明」页只有原则无阈值 → 不能显示「对照 CTCAE N 级」。
2. **放射性骨坏死（ORN）发生率**：本地无来源，页面已按「不给发生率」处理（S05 不做什么）。
3. **发音管 115 天 / 3.15 次每年**：文献均值，来源标注在 `docs/SOURCES.md`，但**未逐条核到原文页码**。
4. **随访节奏**：`followup_schedules` 有 `source_version` 字段，但具体间隔（如「术后 2 年内每 3 月」）来源待补。
5. **吞咽分级口径**：`aspiration_events` 只记「什么形态呛/有没有咳出」，未接 IDDSI 或任何分级体系——这是**有意**的（不做分级），需在 SPEC 写明。
6. **S15 分级页**：同 1。

### P1 急救卡字段 → 并入 SCHEMA（`subjects` 拆出 `emergency_profile`）
