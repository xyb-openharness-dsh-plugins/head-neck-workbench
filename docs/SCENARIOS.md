# 头颈癌工作台 · 场景清单与功能线走查（2026-10-25）

> 依据：`docs/26-CANCER-FEATURE-LINES.md`（三级结构 / L1–L10 / 四段走查 / 场景三段式）
> 证据：`docs/RESEARCH-2026-10-25.md` §4 十二条维度、§5 四条轨道
> 状态：**草案，待用户确认**（G1 未签，不写业务代码）

---

## 0. 一句话

头颈癌的立身之处不在"记录病情"，在**三条会终身改变生活的能力线**：呼吸走哪条道（气管造口）、声音怎么出来（发声方式与发音管）、东西怎么咽下去（进食方式与误吸）。
这三条线**任何一个癌种都替代不了**，也**不能折算成一个"生活质量分数"**。

## 2. 为什么这 10 条不是膀胱癌那 14 条改名字

判据（26 §4.1）：**一级名称一致率 > 70% 且二级顺序一致 → 没认真做本癌种调研。**

| 膀胱癌（已交付） | 头颈癌（本癌种） | 差异性质 |
| --- | --- | --- |
| 看板 / 病情整理 / 分型分期 / 手术 / 灌注 / 改道 / 治疗历程 / 复查 / 指标 / 一图秀 / 急症 / 生活 / 复诊 / 试验（14 个一级） | 看板 / 我的病 / 治疗与手术 / **气道与造口** / **声音与沟通** / 吞咽与营养 / 长期与复诊 / 指标分析 / 心理与家人 / 资料与导出（10 个一级） | 名称一致仅「看板」「指标分析」2 个 → **一致率 20%**，低于 70% 阈值 |
| **灌注**（膀胱内 BCG/化疗，疗程 3 年） | 无对应；改为**放疗**（靶区/剂量/次数）与**用药与不良反应** | 膀胱的"局部长期治疗"在头颈不存在 |
| **改道**（尿流改道三术式） | **气道与造口**（气管造口） | **同名不同物**：肠/尿造口是"换一种方式排泄"，气管造口是"**唯一**的呼吸通道"，堵管 = 窒息（分钟级）。二者耗材、急症、语义全不同 |
| **造口生活**（底盘/渗漏/气味/社交） | **造口日常**（清洁/湿化/遮挡/洗澡）+ **耗材与库存** | 膀胱造口管的是"漏不漏"；气管造口管的是"通不通" |
| 无 | **声音与沟通**（发声方式/发音管/说不出来时） | **膀胱癌完全没有这一维**。全喉切除后失去声音，是本病最不可逆的损失 |
| 无 | **吞咽与营养**里的「呛咳与误吸」 | 膀胱癌无吞咽概念；误吸可无症状（沉默性），且放疗史者风险更高（EV-06） |
| 无 | **长期与复诊**里的「放疗后十年」 | 膀胱癌长周期是 3 年灌注；头颈是**十年**迟发毒性（口干/龋齿/ORN/牙关紧闭/颈动脉狭窄/甲减） |
| 试验与线索（有入口） | **不上**（见 §3-L10） | 无真实登记库支撑 |

**一句话**：膀胱癌的核心是"器官去留"，头颈癌的核心是"**三种能力各自还能剩多少**"。

## 3. L1–L10 逐条「上 / 不上 / 为什么」

| 线 | 上不上 | 为什么 | 头颈癌特有的表达 |
| --- | --- | --- | --- |
| **L1 看板** | 上 | 患者每天只需要一眼：呼吸通不通、今天能不能吃、下次什么时候 | **四条轨道并置**，不做总分；顶部固定"造口状态"与"最近一次发声/吞咽自评" |
| **L2 疾病本体** | 上 | 部位决定一切；同为"头颈癌"的两个人可能没有任何共同治疗经历 | 首屏第二问就是**原发部位**（口腔/口咽/喉/下咽/鼻咽/唾液腺/鼻窦）；HPV/p16 只在口咽显示 |
| **L3 治疗与决策** | 上 | 手术 vs 放疗是两条完全不同的路径，且可先后叠加 | 手术必须**按术式分支**（部分喉/全喉/咽全喉/口腔切除±重建±下颌骨），不能一条时间线 |
| **L4 指标分析** | 上 | 血常规/肝肾/甲功/白蛋白都要看；但**分级口径待裁决**（§8-Q1） | 黏膜炎按 WHO 的"进食形态"更可自评；CTCAE 需检查所见 |
| **L5 安全与症状** | 上（**拆成两条**） | 本癌种的"不舒服"分两类，时间尺度差三个数量级 | **气道与造口**（分钟级：堵管/脱管/出血）与**吞咽与营养**（小时–天级：呛咳/误吸/吃不下）分属两条一级线，**不能合并** |
| **L6 营养与体重** | 上（并入「吞咽与营养」） | 体重是结果，进食方式与误吸是原因；分开会让患者只记结果 | 进食方式（口进/胃管/PEG）是**一等字段**，不是备注 |
| **L7 心理与家庭** | 上 | 失声者在文字互联网里天然缺席；三方（医生/患者/家属）分歧是结构性的（EV-09） | 交互**不能只靠打字**：家属代记是刚需旁路；"说不出口的事"（外形/性/病耻）默认私密 |
| **L8 复诊与随访** | 上 | 随访含影像、内镜、甲功；且"放疗后第 N 年该查什么"没人告诉患者 | 用**关切清单（PCI 式）**而非"问题清单"：不只记"要问什么"，还记"担心什么、有没有被回应"（EV-05） |
| **L9 资料与导出** | 上 | 转诊/二次意见必带；失声者更需要"打印出来给医生看" | 导出必须能**离线打印**（不能只给一个需要登录的链接） |
| **L10 试验与线索** | **不上** | 无真实登记库支撑（本癌种无离线语料，在线通道未接）；26 文档明确"无库就不做入口" | 首页不出现"临床试验"入口；`docs/SPEC.md` 记为**明确不做**，二期有库再开 |

## 5. 场景（患者原话 / 页面接住 / 明确不做什么）

> ⚠️ **所有"患者原话"为推定表达**：本项目未做患者访谈（与膀胱癌项目同一约束），原话由文献记载的症状负担（EV-01/03/04/06/09）改写而成，**未经访谈核实**。真实访谈后必须替换，不得当作已核实素材使用。

### S01 醒来发现脖子上有个洞
- **患者原话**：手术前医生说可能要切喉，醒过来脖子上就有个洞，吸气直接从这里进，说话没声音了。
- **页面接住**：看板 › 今天要知道的（造口状态=终身造口 + 发声方式=待定）→ 气道与造口 › 我的气道（这条通道是**唯一**呼吸入口，不是"伤口"）→ 声音与沟通 › 说不出来的时候（先给能立刻用的：写字板/手机打字/急救卡）
- **不做什么**：不解释"还能不能恢复声音"（取决于术式与康复，属医生判断）；不给康复时间表

### S02 半夜造口堵了
- **患者原话**：半夜觉得喘不上气，摸到造口那儿有干痂堵住了。
- **页面接住**：气道与造口 › 堵管与脱管（置顶，单页可离线打开）→ 明确"这是分钟级"→ 给出**立刻就医/呼叫急救**的条件，与"可以等门诊"的分界
- **不做什么**：**不写处置步骤**（不教怎么清理、不教怎么换管）——本工作台不做处置；只做"什么情况立刻走"

### S03 发音管该换了
- **患者原话**：上次换发音管是三个月前，现在说话又漏气了，是不是该换了？
- **页面接住**：声音与沟通 › 发声方式与发音管（置入日期 + 更换记录 + **115 天/3.15 次每年**参考刻度，标明是文献均值不是个人预测）
- **不做什么**：不说"你该换了"；只给"距上次 N 天 / 文献均值 115 天 / 漏气是常见更换原因之一（来源）"

### S04 吃饭总呛
- **患者原话**：喝粥还行，喝水就呛，有时候呛了也不咳。
- **页面接住**：吞咽与营养 › 呛咳与误吸（记录"什么形态呛/有没有咳出来"；提示**沉默性误吸**：不咳也可能呛进去）→ 若治疗史里有放疗，页面自动带出"放疗史者风险更高"（EV-06）作为**提示**
- **不做什么**：不判断"你有没有误吸"；不建议改食物形态（属言语治疗师/医生）

### S05 放疗后第三年牙疼
- **患者原话**：放疗结束三年了，最近牙疼，牙医说不敢给我拔。
- **页面接住**：长期与复诊 › 放疗后十年（放疗后拔牙是明确风险点；记录"放疗结束日期"→ 自动算"第 N 年"）→ 提示"放疗史必须告诉牙医"
- **不做什么**：不说"能不能拔"；不给 ORN 发生率（本地无来源，G5）

### S06 体重掉了八斤
- **患者原话**：两个月掉了八斤，但我吃着呢。
- **页面接住**：吞咽与营养 › 体重（趋势 + 与进食方式同屏：口进还是靠胃管）→ 若进食方式=口进且体重持续下降，提示"可以问医生要不要营养支持"
- **不做什么**：不诊断"营养不良"；不给"每天要吃多少千卡"

### S07 说不出话怎么报警
- **患者原话**：真出事了我连 120 都打不了。
- **页面接住**：声音与沟通 › 说不出来的时候（急救卡：可打印，写明诊断/术式/造口/过敏/联系人）→ 气道与造口 › 堵管与脱管
- **不做什么**：不承诺"一定有人来"；不替代急救系统

### S08 家里人不知道该做什么
- **患者原话**：我老伴天天问我要不要喝水，我也不知道该让她做什么。
- **页面接住**：心理与家人 › 家里人要做什么（照护者清单：造口湿化、耗材补货、复诊陪同、记录代录）→ 明确区分「本页记录人」与「记录的是谁」
- **不做什么**：不给护理操作步骤（G4）；不把家属变成"执行医嘱的人"

### S09 我怕但不想跟家里说
- **患者原话**：晚上睡不着，老想最坏的情况，但不想让他们担心。
- **页面接住**：心理与家人 › 我现在的感受（**默认私密**，不进一图秀/摘要/导出）
- **不做什么**：不做心理评估分级；出现自伤念头 → 直接给"联系当地急救或你的治疗团队"，不做危机干预话术

### S10 复诊前想不起来要问什么
- **患者原话**：每次进诊室就懵，出来才想起来要问的没问。
- **页面接住**：长期与复诊 › 关切清单（PCI 式：担心什么 / 问了没有 / 医生怎么答（原文）/ 有没有被回应）→ 复诊带什么（一页摘要，可打印）
- **不做什么**：不替患者排序"哪个问题更重要"

### S11 免疫治疗后身上起疹子
- **患者原话**：打了两次免疫，身上起疹子，还拉肚子。
- **页面接住**：治疗与手术 › 用药与不良反应（记录症状与出现时间；共识要求"治疗全程密切监测 irAE"EV-08）
- **不做什么**：不判断"是不是免疫相关不良反应"；不说"要不要停药"

### S12 报告上写 CPS 80
- **患者原话**：病理报告写 PD-L1 CPS 80，是不是说明我 80% 的癌细胞阳性？
- **页面接住**：我的病 › 病理报告原文（照录 CPS 数值 + 检测方法 + 标本类型）→ 名词与不确定（解释 CPS 分子含淋巴细胞与巨噬细胞，**可以 >100**，不等于肿瘤细胞阳性比例；CPS 与 TPS 不是同一把尺）
- **不做什么**：不解释"这个数好不好"；不给阈值对应的用药建议（EV-08 的方案选择属医生）

### S13 肩膀抬不起来
- **患者原话**：颈清扫那侧胳膊抬不到头，梳头费劲。
- **页面接住**：治疗与手术 › 手术与切除范围（颈清扫分区 + 副神经是否保留）→ 功能自述"能不能做到某个动作"（梳头/穿衣/提物）
- **不做什么**：不做量表评分；不给康复动作处方

### S14 别人听不清就懒得说了
- **患者原话**：说三遍人家还听不清，我就不说了。
- **页面接住**：心理与家人 › 说不出口的事（社交退缩、外形、性，默认私密）+ 声音与沟通 › 能说到什么程度
- **不做什么**：不把"社交退缩"做成量表；不评判

### S15 抽血单出来一堆箭头
- **患者原话**：化验单上一半带箭头，我不知道哪个要紧。
- **页面接住**：资料与导出 › 我的资料与草稿（录入）→ 指标分析 › 指标卡片 / 一图秀 / 分级说明（对照 CTCAE）
- **不做什么**：不判断「要不要紧」；分级只做对照并显示区间与来源，不写处置

### S16 资料散在手机相册里
- **患者原话**：报告全在相册，找一次翻半天，去医院还得重拍。
- **页面接住**：资料与导出 › 我的资料与草稿（清单 + 待核对草稿）→ 导出给医生
- **不做什么**：解析结果只做候选，逐项确认才入库；看不清的留空不猜

### S17 医生说换方案，我听不懂第几线
- **患者原话**：医生说要换二线，我连一线是什么都没搞清。
- **页面接住**：治疗与手术 › 治疗线（旧线标结束不删除）
- **不做什么**：不解释「为什么要换」（属医生判断）；不知道线数时允许「说不清」

## 6. 私密与不可计算项

| 项 | 处理 |
| --- | --- |
| 心理感受、家庭矛盾、外形与性 | `visibility='private'` 默认；三处出口（一图秀/摘要/导出）各自过滤 |
| 症状自评（呛咳次数、疼痛分） | **不做趋势线**，只做"最近 N 次"列表（患者自评主观性强，折线会制造虚假精确） |
| 黏膜炎分级 | 可分级，但**口径待裁决**（§8-Q1）；裁决前不显示徽章 |
| 发音管"还能用多久" | 只给"距上次 N 天"与文献均值，**不预测** |
| 体重 | 可折线（客观、可测），但需与进食方式同屏，否则会被误读为"只是瘦了" |
