# 需求起点

来源：初始化配置。用户、场景和流程是有效的SPEC互动素材；继承会话中已有明确确认，其余不能仅因配置通过校验就当成设计定稿或研究验证。

目标用户：头颈癌患者（口腔/口咽/喉/下咽/鼻咽/唾液腺）与家属照护者；尤其面向全喉切除与气管造口者、放疗后长期副作用者

场景：头颈癌不是一个病：原发部位不同，手术范围、功能损失与放疗靶区都不同；HPV 阳性口咽癌与吸烟饮酒相关口腔癌是两条人群与预后都不同的病；保喉与全喉切除的取舍代价是声音；放疗后口干、吞咽困难、张口受限与骨坏死风险要跟十年以上。患者要在门诊几分钟里听懂这些，并长期自己管住气管造口与功能康复

核心流程：
1. 进入后先确认原发部位（口腔/口咽/喉/下咽/鼻咽/唾液腺）与病因状态（HPV p16 / EBV / 未检测），不同部位看到不同的功能损失清单
2. 记录本次治疗或检查（手术方式与是否保喉/是否气管造口、放疗靶区与剂量、气管造口护理），可粘贴报告由 AI 出草稿后逐项核对
3. 在时间轴上看到功能变化（言语、吞咽、口干、张口度、肩臂）与放疗后毒性累积
4. 复诊前把要问的问题与近期记录整理成一页可打印摘要，带回门诊

完成结果：复诊时能说清「我在哪个部位、做过什么、现在最影响生活的是哪一件事」，并带走一页摘要；气管造口的日常护理与急症边界随时可查
